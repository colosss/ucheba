# Лабораторные работы по Python, 6 семестр

В этой папке лежат семь лабораторных работ. Каждая лабораторная оформлена в своей директории:

- `lr1` - класс машины с логированием смены состояния.
- `lr2` - анализ динамики цен из Excel-файла Росстата/ЕМИСС.
- `lr3` - SQLite-база данных предметной области "Клиническая больница".
- `lr4` - SQLite + SQLAlchemy ORM для предметной области "Игровой магазин".
- `lr5` - задача об обедающих философах на потоках.
- `lr6` - асинхронный генератор случайных чисел.
- `lr7` - Telegram-бот для управления финансами на SQLite.

Тесты находятся рядом с каждой лабораторной: `lr1/tests`, `lr2/tests`, ..., `lr7/tests`.

## Подготовка окружения

Все зависимости описаны в `pyproject.toml` и ставятся через `uv`.

Перейдите в папку с лабораторными:

```bash
cd 6_sem
```

Создайте/обновите виртуальное окружение:

```bash
uv sync --dev
```

Если `uv` ругается на кэш в домашней директории, используйте временный кэш:

```bash
UV_CACHE_DIR=/tmp/uv-cache uv sync --dev
```

Для запуска тестов и скриптов дальше можно использовать обычный вариант:

```bash
uv run pytest
```

В этой рабочей среде также полезно указывать writable-кэш для Matplotlib:

```bash
UV_CACHE_DIR=/tmp/uv-cache MPLCONFIGDIR=/tmp/matplotlib uv run pytest
```

## Проверить все лабораторные сразу

Из папки `6_sem`:

```bash
UV_CACHE_DIR=/tmp/uv-cache MPLCONFIGDIR=/tmp/matplotlib uv run pytest
```

Ожидаемый результат:

```text
39 passed
```

## ЛР1: Класс "Машина"

### Что сделано

В папке `lr1` реализован класс `Car`.

Файлы:

- `lr1/car.py` - основной класс и перечисление состояний.
- `lr1/main.py` - пример запуска.
- `lr1/tests/test_car.py` - тесты лабораторной.

Машина поддерживает состояния:

- `стоп`;
- `поворот налево`;
- `поворот направо`;
- `движение вперед`;
- `разгон`.

При каждой смене состояния в текстовый лог записывается строка:

```text
дата и время; предыдущее состояние; текущее состояние
```

Если установить то же состояние повторно, новая запись в лог не добавляется.

Код написан с Type Hinting.

### Запустить пример

```bash
uv run python -m lr1.main
```

После запуска появится файл `lr1/car.log`. В нем будут переходы машины между состояниями.

### Запустить тесты ЛР1

```bash
uv run pytest lr1/tests
```

Проверяется:

- начальное состояние машины;
- формат и содержимое лог-файла;
- отсутствие записи при повторной установке того же состояния.

## ЛР2: Анализ цен из Excel

### Что сделано

В папке `lr2` реализована обработка файла `data.xls`.

Файлы:

- `lr2/data.xls` - исходный Excel-файл с данными.
- `lr2/prices.py` - загрузка, очистка, расчет статистики и построение графика.
- `lr2/main.py` - запуск анализа.
- `lr2/tests/test_prices.py` - тесты лабораторной.

В текущем варианте программа анализирует товар, который есть в приложенном файле:

- `Говядина (кроме бескостного мяса), кг`.

Для каждого найденного товара считается:

- динамика цен по месяцам;
- среднее значение цены;
- медиана;
- отклонение каждой месячной цены от среднего;
- отклонение каждой месячной цены от медианы.

Также строится график динамики цен и сохраняется в `lr2/price_dynamics.png`.

Код написан с Type Hinting.

При запуске на текущем файле скрипт выводит таблицу цен за 2014-2015 годы, среднее значение, медиану, отклонения от среднего и медианы, а также сохраняет график.

### Запустить анализ

```bash
UV_CACHE_DIR=/tmp/uv-cache MPLCONFIGDIR=/tmp/matplotlib uv run python -m lr2.main
```

Если окружение не требует отдельных кэшей, можно короче:

```bash
uv run python -m lr2.main
```

### Запустить тесты ЛР2

```bash
UV_CACHE_DIR=/tmp/uv-cache MPLCONFIGDIR=/tmp/matplotlib uv run pytest lr2/tests
```

Проверяется:

- извлечение данных из таблицы, похожей на выгрузку ЕМИСС;
- расчет среднего, медианы и отклонений.

## ЛР3: SQLite-база "Клиническая больница"

### Что сделано

В папке `lr3` реализована база данных SQLite без ORM.

Файлы:

- `lr3/hospital.py` - схема, заполнение тестовыми данными и SQL-запросы.
- `lr3/main.py` - демонстрационный запуск.
- `lr3/tests/test_hospital.py` - тесты лабораторной.

В базе больше минимально требуемых четырех таблиц:

- `departments` - отделения больницы;
- `doctors` - врачи;
- `patients` - пациенты;
- `appointments` - приемы;
- `treatments` - назначения и лечение.

Реализовано 5 запросов:

- врачи выбранного отделения;
- приемы выбранного пациента;
- количество пациентов по отделениям;
- нагрузка врачей по числу приемов;
- активные лечения.

Код написан с Type Hinting.

### Запустить пример

```bash
uv run python -m lr3.main
```

Скрипт создаст базу в памяти, заполнит ее демонстрационными данными и выведет результаты всех пяти запросов.

### Запустить тесты ЛР3

```bash
uv run pytest lr3/tests
```

В задании требуется минимум 2 теста под каждый запрос. Здесь 5 запросов и 10 тестов: по 2 теста на каждый запрос.

Проверяется:

- фильтрация врачей по отделению;
- пустой результат для неизвестного отделения;
- сортировка приемов пациента;
- корректные врач и отделение в приемах;
- подсчет пациентов по отделениям;
- изменение подсчета после добавления приема;
- сортировка нагрузки врачей;
- изменение нагрузки после нового приема;
- выбор только активных лечений;
- пустой список активных лечений после закрытия назначений.

## ЛР4: SQLAlchemy ORM, база "Игровой магазин"

### Что сделано

В папке `lr4` реализована SQLite-база через ORM SQLAlchemy.

Файлы:

- `lr4/game_store.py` - ORM-модели, заполнение данными и запросы.
- `lr4/main.py` - демонстрационный запуск.
- `lr4/tests/test_game_store.py` - тесты лабораторной.

В базе используются таблицы:

- `categories` - жанры/категории игр;
- `publishers` - издатели;
- `games` - игры;
- `customers` - покупатели;
- `orders` - заказы;
- `order_items` - позиции заказов.

Реализовано 5 ORM-запросов:

- игры выбранной категории;
- самые продаваемые игры;
- суммы покупок клиентов;
- игры с малым остатком на складе;
- заказы с позициями.

Код написан с Type Hinting и использует современный стиль SQLAlchemy 2.x: `DeclarativeBase`, `Mapped`, `mapped_column`, `select`.

### Запустить пример

```bash
uv run python -m lr4.main
```

Скрипт создаст SQLite-базу в памяти, заполнит ее данными игрового магазина и выведет результаты пяти ORM-запросов.

### Запустить тесты ЛР4

```bash
uv run pytest lr4/tests
```

В задании требуется минимум 2 теста под каждый запрос. Здесь 5 запросов и 10 тестов: по 2 теста на каждый запрос.

Проверяется:

- выбор игр по категории;
- пустой результат для неизвестной категории;
- сортировка топа продаж;
- ограничение количества строк в топе;
- расчет трат клиентов только по оплаченным заказам;
- исключение созданных, но не оплаченных заказов;
- поиск игр с малым остатком;
- пустой результат при слишком низком пороге;
- вывод всех позиций заказов;
- наличие статуса заказа в результате.

## ЛР5: Обедающие философы

### Что сделано

В папке `lr5` реализована классическая задача об обедающих философах.

Файлы:

- `lr5/philosophers.py` - потоковая модель философов и вилок.
- `lr5/main.py` - демонстрационный запуск.
- `lr5/tests/test_philosophers.py` - тесты лабораторной.

Модель:

- 5 философов;
- 5 вилок;
- каждый философ находится в состоянии `размышляет` или `ест`;
- чтобы есть, философ берет две вилки;
- вилки представлены через `threading.Lock`;
- порядок взятия вилок нормализован, чтобы избежать deadlock.

Код написан с Type Hinting.

### Запустить пример

```bash
uv run python -m lr5.main
```

Скрипт запустит 5 потоков и выведет, сколько раз каждый философ поел.

### Запустить тесты ЛР5

```bash
uv run pytest lr5/tests
```

Проверяется:

- все 5 философов успевают поесть нужное число раз;
- нельзя создать стол не на 5 философов;
- после завершения симуляции все снова находятся в состоянии размышления.

## ЛР6: Асинхронный генератор случайных чисел

### Что сделано

В папке `lr6` реализован асинхронный генератор.

Файлы:

- `lr6/random_generator.py` - асинхронный генератор и helper для сбора значений.
- `lr6/main.py` - демонстрационный запуск.
- `lr6/tests/test_random_generator.py` - тесты лабораторной.

Функция `random_numbers` возвращает случайные числа в течение заданного времени. Можно настроить:

- длительность генерации;
- интервал между числами;
- минимальное значение;
- максимальное значение;
- генератор `random.Random` для воспроизводимых тестов.

Код написан с Type Hinting.

### Запустить пример

```bash
uv run python -m lr6.main
```

Пример будет примерно одну секунду печатать случайные числа.

### Запустить тесты ЛР6

```bash
uv run pytest lr6/tests
```

В задании требуется минимум 3 теста. Здесь 4 теста.

Проверяется:

- числа находятся в заданных границах;
- при нулевой длительности возвращается пустой список;
- отрицательная длительность вызывает ошибку;
- некорректные границы вызывают ошибку.

## ЛР7: Telegram-бот для управления финансами

### Что сделано

В папке `lr7` реализована основа Telegram-бота для учета личных финансов.

Файлы:

- `lr7/finance_bot.py` - база данных, бизнес-логика, обработчик команд и polling Telegram API.
- `lr7/main.py` - точка запуска бота.
- `lr7/tests/test_finance_bot.py` - тесты лабораторной.

В базе больше минимально требуемых пяти таблиц:

- `users` - пользователи Telegram;
- `accounts` - счета;
- `categories` - категории доходов и расходов;
- `transactions` - операции;
- `budgets` - месячные бюджеты;
- `goals` - финансовые цели.

Реализованы запросы и операции:

- создание пользователя;
- создание счета;
- создание категории;
- добавление дохода;
- добавление расхода;
- баланс по счетам;
- сводка за месяц;
- расходы по категориям;
- прогресс бюджета;
- список целей;
- последние операции.

Команды бота:

- `/start` - подготовить пользователя и основной счет;
- `/help` - показать доступные команды;
- `/account название` - создать счет;
- `/income счет категория сумма` - добавить доход;
- `/expense счет категория сумма` - добавить расход;
- `/summary ГГГГ-ММ` - показать сводку за месяц;
- `/balance` - показать баланс по счетам;
- `/budget категория ГГГГ-ММ лимит` - задать бюджет;
- `/goals` - показать цели;
- `/recent` - показать последние операции.

Код написан с Type Hinting.

### Запустить тесты ЛР7

```bash
uv run pytest lr7/tests
```

Проверяется:

- наличие всех таблиц базы данных;
- расчет баланса с учетом доходов и расходов;
- месячная сводка;
- расходы по категориям;
- прогресс бюджета;
- цели;
- последние операции;
- обработка команд `/start`, `/income`, `/expense`, `/balance`;
- сообщение об ошибке при неправильной сумме.

### Запустить Telegram-бота

Для реального запуска нужен токен Telegram-бота от BotFather.

Linux/macOS:

```bash
export TELEGRAM_BOT_TOKEN="ваш_токен"
uv run python -m lr7.main
```

Windows PowerShell:

```powershell
$env:TELEGRAM_BOT_TOKEN="ваш_токен"
uv run python -m lr7.main
```

Если токен не указан, скрипт не падает, а выводит сообщение:

```text
Укажите TELEGRAM_BOT_TOKEN, чтобы запустить Telegram-бота.
```
