# Курсовой проект по САОД: бюро проката автомобилей

Готовый C++17 проект по варианту:

- предметная область: обслуживание клиентов в бюро проката автомобилей;
- хеширование: открытое хеширование, то есть цепочки в хеш-таблице;
- сортировка списка: шейкерная;
- список: циклический двунаправленный;
- обход дерева: обратный обход АВЛ-дерева;
- поиск слова/фрагмента в тексте: алгоритм Боуера-Мура.

## Слои проекта

Проект оставлен в исходной структуре `src/domain`, `src/structures`, `src/service`, но доведен до рабочей слоистой архитектуры.

- `domain` - сущности предметной области: `Client`, `Car`, `RentalRecord`.
- `structures` - собственные структуры данных: АВЛ-дерево, хеш-таблица с открытым хешированием, циклический двунаправленный список с шейкерной сортировкой.
- `repository` - хранение сущностей в структурах данных и загрузка/сохранение в `src/data/*.txt`.
- `service` - бизнес-логика: проверки при выдаче, возврате, ремонте, удалении.
- `ui` - простой терминальный интерфейс с управлением цифрами.
- `utils` - валидация форматов, строковые функции, БМ-поиск.

## Сборка

### Через CMake

```bash
cmake -S . -B build
cmake --build build
./build/algo_curs
```

### Через g++ без CMake

```bash
g++ -std=c++17 -Isrc \
    src/main.cpp \
    src/domain/client.cpp src/domain/car.cpp src/domain/rentalrecord.cpp \
    src/repository/client_repository.cpp src/repository/car_repository.cpp src/repository/rental_repository.cpp \
    src/service/rental_service.cpp \
    src/ui/console_ui.cpp \
    src/utils/string_utils.cpp src/utils/boyer_moore.cpp src/utils/validation.cpp \
    src/structures/avltree.cpp src/structures/hashtable.cpp \
    -o algo_curs
./algo_curs
```

На Windows перед запуском в консоли можно выполнить:

```bat
chcp 65001
```

## Данные

Файлы данных лежат в `src/data`:

- `client.txt` - клиенты;
- `car.txt` - автомобили;
- `rentals.txt` - активные записи проката.

При изменении данных программа автоматически сохраняет файлы. В главном меню есть пункт `6 - Загрузить демонстрационные данные`, который возвращает тестовый набор.

## Что демонстрируется

- Клиенты хранятся в АВЛ-дереве по номеру водительского удостоверения.
- Автомобили хранятся в хеш-таблице с открытым хешированием по госномеру.
- Записи проката хранятся в циклическом двунаправленном списке, упорядоченном по госномеру автомобиля. После добавления применяется шейкерная сортировка.
- Просмотр всех клиентов и поиск клиента по фрагменту ФИО или адреса идут обратным обходом АВЛ-дерева; поиск использует алгоритм Боуера-Мура.
- Поиск автомобиля по марке выполнен последовательным просмотром хеш-таблицы и БМ-поиском по строке марки. Альтернатива - отдельный индекс по марке, но для учебной демонстрации выбранный способ проще и не требует дублирования структуры.

## Основные проверки

- Нельзя выдать автомобиль, если он отсутствует, уже выдан или находится в ремонте.
- Нельзя выдать второй автомобиль клиенту, у которого уже есть активная запись проката.
- Нельзя отправить в ремонт автомобиль, который выдан клиенту.
- Нельзя удалить клиента с активным прокатом.
- Нельзя удалить автомобиль, который выдан клиенту или отмечен как отсутствующий.
- При выдаче и возврате автоматически меняется признак наличия автомобиля.

## Форматы ввода

- Номер водительского удостоверения: `RR AA NNNNNN`, пример: `77 АВ 123456`.
- Госномер автомобиля: `ANNNAA-NN`, пример: `А123ВС-77`.

Допускаются как русские, так и визуально похожие латинские буквы в серии/номере. При сохранении они приводятся к русским буквам.
